# morales_mobprog

I integrated the image into the NewsFeedCard widget by using a nullable boolean variable called hasImage. This variable allows the widget to dynamically determine whether an image should be displayed in a post. Inside the build() method, I used a conditional statement that checks if hasImage is set to true. When the condition is true, the PostImage widget is rendered and displays the image from the specified asset path. Otherwise, the image section is skipped, and only the text content of the post is shown. This approach makes the NewsFeedCard reusable and flexible because it can handle both posts with images and posts without images using the same widget. As a result, the news feed behaves more like a real social media application where different posts may contain different types of content.

I managed the posts and notifications efficiently by creating reusable widgets and simply changing the data such as the name, post title, description, content, date, and number of likes. This approach reduced code duplication and made it easier to add or modify Marvel-themed content. For the enhancement, I customized the application by adding a Marvel-inspired theme, new notification entries, and unique posts featuring different Marvel characters, especially Doctor Doom. One challenge I encountered was choosing a color palette that looked appealing because some colors appeared too light and dull. I addressed this by experimenting with different color combinations until I found a better contrast using darker shades and accent colors. Another challenge was organizing multiple posts and notifications, which I solved by using reusable components to keep the code clean, consistent, and easier to maintain.
